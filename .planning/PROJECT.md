# Project: 3F (Futuro Forbes)

## Mission
To empower personal financial freedom through comprehensive control, automated tracking, and deep analysis of expenses and investments.

## Context
3F is a self-hosted financial management system designed for personal use. It focuses on double-entry accounting integrity while maintaining a modern, reactive interface.

## Tech Stack
- **Backend**: FastAPI, SQLModel (Alchemy 2.0 + Pydantic v2), Jinja2 Templates.
- **Frontend**: Alpine.js, AdminLTE 4, Bootstrap 5, Neon-themed CSS.
- **Database**: SQLite (Development) / PostgreSQL (Production ready).
- **Core Engine**: LedgerEngine for balance calculations and transaction integrity.

## Design Principles
- **Aesthetic Excellence**: High-contrast dark mode (Neon/Cyberpunk aesthetic).
- **Extensibility**: Modular plugin system for new features (OCR, banking bank integration).
- **Data Privacy**: Local-first/Self-hosted data ownership.
- **Integrity**: Strict double-entry accounting rules.

## Brand Identity
- **Name**: Fer Futuro Forbes (3F)
- **Vibe**: Professional yet cutting-edge (High-tech finance).
- **Palette**: Dark backgrounds with vibrant neon highlights (Indigo, Primary Blue, Warning Yellow).
